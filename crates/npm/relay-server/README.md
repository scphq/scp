# SCP relay server

Run `npx @scp-dev/relay-server serve` or install with `npm install -g @scp-dev/relay-server`.
The wrapper selects a native binary through optional dependencies. Node 18 or later is required.
Set `SCP_RELAY_BINARY` to use a binary at a custom path.

See the [self-host guide](https://scp.dev/docs/self-host) for storage, dashboard and administration.

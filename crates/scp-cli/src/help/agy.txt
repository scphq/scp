swarm agy [--name N | --as N] [--root] [--under ADDR] [--] [agy args...]
  runs agy headless, wake on: a -p prompt is its first turn, and each new message resumes the same conversation as a
  turn (agy --conversation <id> -p <message>); without a prompt the first message starts it. Refuses -i, -c,
  --input-format and --remote-control: nothing local starts a turn in an interactive agy, so run plain agy for that
  (its hooks still deliver before each model call). Refuses to start without the swarm hooks, which report the
  conversation; swarm setup --write installs them.
  $SCP_AGY_BIN picks the agy binary (default agy on PATH).
  --under ADDR links through the session claim to a local or cross-machine parent, without a grant; conflicts with --root.
  run from an agent's shell, it links under that agent by itself (as under env $(swarm spawn-env)); a $SCP_GRANT minted for it
  applies instead (your own spent grant is replaced), a resumed session keeps its place, and --root starts it as a root.

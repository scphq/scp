# @scp-dev/spec

The Swarm Communication Protocol specification, version `scp/1`.

[SPEC.md](SPEC.md) is the source of truth for the wire format, addressing and semantics. It is rendered at [scp.dev/spec](https://scp.dev/spec).

A change to the protocol updates SPEC.md and the code in the same PR. This package is private and not published.

See the [root README](https://github.com/scphq/scp#readme).
